# Krishiv Patel — Portfolio

A responsive, recruiter-facing single-page portfolio built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly, or run a small local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy on GitHub Pages

1. Create a repository such as `portfolio` or `Krishiv100.github.io`.
2. Upload the contents of this folder to the repository root.
3. In GitHub: **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`.
5. Save. GitHub will provide the public URL after deployment.

## Deploy on Vercel

Import the GitHub repository into Vercel. No build command is required because this is a static site.

## Customize

- `index.html` — content and links
- `styles.css` — visual design
- `script.js` — theme toggle, mobile navigation, reveal animation, copy-email behavior
- `assets/Krishiv_Patel_Resume.pdf` — résumé download
